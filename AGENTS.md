# AGENTS.md

## Upstream

- Canonical upstream: `https://github.com/Flaconi/terraform-cloudflare-records`.

## Protected Branches

- `master` and `sync/upstream` are protected.
- Never push or force-push directly to `master` or `sync/upstream`. Always go through a reviewed PR.

## Upstream Sync Workflow

1. Fetch `upstream`.
2. Create a dated working branch from `sync/upstream`: `sync/upstream-YYYY-MM-DD`.
3. Merge the intended upstream ref into the working branch.
4. Resolve conflicts deliberately (do not blindly accept either side).
5. Open a reviewed PR from the working branch into `sync/upstream`.
6. After merge, open a second reviewed PR from `sync/upstream` into `master`.

## Pre-PR Checks

Before opening any sync/integration PR, run:

```sh
make lint
make gen
make test
```

- Commit any docs regenerated by `make gen`.
- The working tree must be clean before opening the PR.

## Releases

- Release only from a merged `master`.
- Tag using stable SemVer: `vX.Y.Z`.
- Publish a GitHub release after all checks pass.

## Fork-Specific Patches

- Keep local fork-specific patches isolated from upstream code.
- Document each patch's purpose and location to minimize future merge conflicts.
